# Dev Toolbox

A JSON and API toolkit for developers.

## Tools

- **JSON Formatter** — Prettify or minify any JSON in one click.
- **JSON Diff** — Compare two JSON documents and see exactly what changed.
- **API Tester** — Send HTTP requests and inspect responses, right from your desktop.
- **JSON Converter** — Convert JSON to YAML, CSV, or TypeScript interfaces.

## Download

Visit the [download page](https://MeetVaghasia2274.github.io/dev-toolbox/) for one-click install, or go straight to the [latest release](https://github.com/MeetVaghasia2274/dev-toolbox/releases/latest).

| Platform | File |
|---|---|
| Windows | `Dev Toolbox Web Setup x.y.z.exe` — small installer that downloads the app when run (requires internet) |
| macOS | `.dmg` |
| Linux | `.AppImage` |

## Install

1. Download the installer for your platform.
2. Run it — the app installs itself.
3. Done. Dev Toolbox updates itself automatically when a new version is released.

> **Windows users:** If you see a "Windows protected your PC" dialog, click **More info** then **Run anyway**. The app is not code-signed yet.
